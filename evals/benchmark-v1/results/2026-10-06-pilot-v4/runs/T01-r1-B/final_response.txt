## Summary

**Root cause** — `boltons/strutils.py:172`: the teen-detection branch compared the tens digit against `'2'` instead of `'1'`. The branch is meant to force `th` for teens (10–19), but `'2'` instead hijacked 21/22/23. Observed before the fix:

| input | before | after |
|---|---|---|
| 11 / 12 / 13 / 111 | `11st` / `12nd` / `13rd` / `111st` | `11th` / `12th` / `13th` / `111th` |
| 21 / 22 / 23 / 121 | `21th` / `22th` / `23th` / `121th` | `21st` / `22nd` / `23rd` / `121st` |

**Change** — one-character fix (`'2'` → `'1'`) in `boltons/strutils.py`, plus doctest examples documenting teen/twenty behavior. Preserved behavior: non-digit-terminated strings pass through unchanged (`ordinalize('hi') == 'hi'`), `ext_only` returns the bare suffix (`''` for passthrough inputs), and digit-terminated inputs still get a suffix.

**Regression tests** — new `agent_tests/test_strutils_ordinalize.py` (14 tests): teens, embedded teens, 21–23, negatives, string inputs, passthrough/`ext_only`, and a 0–1200 sweep against an independently written rule.
