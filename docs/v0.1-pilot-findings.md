# v0.1 live pilot: what we actually learned

The raw campaign remains on the
[`benchmark-v1` branch](https://github.com/Anhao1314/deep-native/tree/benchmark-v1)
at commit [`25c4cab`](https://github.com/Anhao1314/deep-native/commit/25c4cabdf7694b6cb77e2f485ae70cfde18bacf2).
It is intentionally not merged wholesale into the product branch because the retained
artifacts add hundreds of thousands of lines.

## Retained preliminary sample

The planned 60-run campaign was paused after 21 completed runs:

- Raw DeepSeek (A): 10 runs
- DeepSeek + Deep Native v0.1 (B): 11 runs
- complete matched pairs: 10
- extra unpaired run: T08-r2-B

Matched task success was **8/10 for Raw** and **7/10 for Deep Native**.
Pairwise outcome: **0 B wins, 1 B loss, 9 ties**.

This is a preliminary stopped sample. It is not a formal population claim that the
Skill is ineffective.

## Behavior changed, quality did not improve

Trace review found:

- actual continued work after a failed check: Raw **4/5**, Deep Native **10/10**;
- a later passing check after a failed check: Raw **4/5**, Deep Native **6/10**;
- total tool calls: Raw **278**, Deep Native **395**;
- median tool calls per run: Raw **29**, Deep Native **36**;
- paired median agent-time ratio B/A: **1.20x**;
- paired median context-processing-token ratio B/A: **1.21x**.

The useful signal is not “v0.1 won.” It did not. The useful signal is that the Skill
changed persistence/tool behavior, but the extra work did not reliably become better
task outcomes.

## What was not successfully measured

Two intended mechanisms were not validly exercised:

- **verification staleness (T09):** both arms had zero valid qualifying observations
  after trace review; automatic markers had mistaken non-functional commands such as
  version queries for verification.
- **interruption recovery (T10):** both arms were interrupted before meaningful code
  progress. Deep Native state was consulted, but there was no substantive checkpoint
  to demonstrate recovery benefit.

Those mechanisms therefore remain unproven, not disproven.

## Environment confounder

The retained traces contained **17 denied shell/temp operations affecting 14 runs**.
The failures included heredoc/native temp-path behavior and consumed attempts/budget.
They affected both arms at different observed frequencies, so the retained result
cannot isolate a pure Skill effect.

## Product decision

v0.2 Candidate changes direction:

1. remove mandatory lifecycle ceremony from simple tasks;
2. introduce FAST / STANDARD / DEEP escalation;
3. classify failures before retrying;
4. reserve persistent checkpoint/evidence runtime for genuinely deep work;
5. fix the next benchmark so stale-evidence and recovery mechanisms are actually hit.

The v0.1 Skill commit remains frozen at
[`fda3dd0`](https://github.com/Anhao1314/deep-native/commit/fda3dd010e7de8f8c1ee1953e006e577464aa3d6)
as the baseline for future ablations.
